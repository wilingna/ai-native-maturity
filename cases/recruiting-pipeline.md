# Case：AI 招聘全链路闭环 / AI-Native Recruiting Pipeline

> 一句话结果：把招聘从"人肉接力"改成"AI 接力、人做关键判断"——一条端到端流程，多个 AI 节点上线，且进了 SOP、每个节点有人对结果负责。

## 背景 Context
- 组织：一家约 300 人的科技制造企业，HR 团队主导推动
- 工作基质（第 0 问）：**会议型 + 系统型**——决策在会上做，招聘过程留痕在招聘系统里；没有真正的"工作大群"
- 起点水位：流程零 AI 介入——JD 撰写、简历筛选、Offer 测算全靠人肉，耗时长、质量不稳
- 技术底座：内网部署的国产大模型 + 低代码编排（数据不出内网，满足合规）

## 做了什么 What we did（映射六阶段）
- **⓪定位**：没有把 agent 放进群聊，而是嵌进招聘系统的流转节点和面试/评审会议里。
- **②打捞**：把高质量 JD 与岗位画像沉淀成模板库，喂给模型，持续提升精准度。
- **③重构**：把 AI 嵌进招聘 SOP 的关键节点，每个节点都明确"谁对结果负责"——不是把 AI 贴在旧流程上，是重新设计了这条流程。
- **④放大**：从单点扩到全链路多节点接力，跑通一条可复制的端到端范式，并作为后续其他部门端到端试点的参考方法。

## 架构 How it works
```
提需求 →[JD生成]✅→ 简历采集 →[简历筛选]✅→ 经理+HR共审 →[邀约话术]✅
   → 视频面试 +[会议转录]⚠️→ 面试评价(人工) →[Offer测算]✅→ 审批/入职建档 → 闭环

   ✅ = AI 已上线    ⚠️ = 待优化    (人工) = 刻意保留人来把关
```
- **JD 生成**：提需求即触发，审批后自动同步招聘系统建岗
- **简历筛选**：自动评分 + 推荐理由 + 风险提示
- **邀约话术**：业务与 HR 共同认可后生成
- **Offer 测算**：输入候选人现薪/期望/在手 offer，输出 2 个成本最优方案 + 合规校验（独立部署、权限隔离）

**致命三要素自检**：Offer 测算节点接触私密薪酬数据，因此**不读外部不可信内容、不对外发送**——只出方案，由人决策和发出。简历筛选节点读外部投递内容，因此不接触薪酬库。

## 结果 Results
- 简历筛选：单份从约 20 分钟压到 2 分钟
- JD 撰写：从约 30 分钟缩短到 3 分钟（质量更稳，靠模板库沉淀）
- 维度变化：场景与流程 L1 → **L3**（已进 SOP、有人负责）；知识与数据 L1 → L3
- 上线节奏：全链路于 2026 年 9 月正式上线

## 还没做好的 What's still rough
- 会议转录目前只能外放收音，结构化评分较弱
- 面试评价仍需人工写回系统（目标：结构化评分直接在招聘系统里提交，从"填空"变"一键确认"）
- 部分外部渠道的简历采集还靠半自动（渠道反爬限制）
- **状态是散的，拼不出一条完整轨迹**（治理维度的真实短板）——数据分散在编排平台日志、招聘系统、面试官手里，目前答不出"这个候选人从提需求到 offer，AI 在哪几步给了什么建议、人在哪几步改了什么、为什么最后定这个方案"。
  下一步不是重构，是**先把日志记起来**：一行一条，只追加不修改——`流程实例ID / 节点 / 时间 / 输入摘要 / AI 输出 / 人的动作（采纳·改了·推翻）/ 改了什么`（模板见 [`docs/honest-metrics.md`](../docs/honest-metrics.md)）。
  成本几乎为零、不依赖任何平台，却同时换来三样东西：断点恢复、审计轨迹、以及 **HITL 率**（Human-In-The-Loop，人工介入率）这个比"效率提升 X%"硬得多的进步指标。

> ⚠️ **一个反面教训：平台归属没定之前，不要做深度重构。**
> 编排平台可能从自建切换到公司统一平台。此时在旧平台上做架构改造是给一块可能要废弃的地基加固——
> 而**日志是数据不是代码，搬到哪都还是你的**。先做不会白做的那一半。

## 下一步 What's next
正在把各节点的 skill 整合成一个"**数字招聘员工**"：不再是多个分散节点各干各的，而是一个对整条链路负责的 agent 角色，人退到审核和例外处理位——这是从 L3 往 L4 走的那一步，前提是上面的日志和 owner 先到位（先装刹车，再给自主权）。

## 可迁移的经验 Takeaways
1. **先答第 0 问**：这家组织没有工作大群，所以 agent 落在系统节点和会议里，而不是 IM。
2. **AI 接力，人做关键判断**：把人从"填空/搬运"挪到"确认/把关"，而不是妄想一步到位全自动。
3. **进 SOP 才算数**：干一次是玩具，写进流程、定好谁负责，才真正上了一级（L2→L3 的唯一分水岭）。
4. **诚实标注"待优化"**：哪些是 AI、哪些还得靠人，画清楚——比假装全自动可信得多。
